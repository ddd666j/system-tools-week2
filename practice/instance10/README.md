# 实例 10：使用 tracemalloc 验证流式处理的内存优势

## 原理

`readlines()` 会把全部文本行和转换后的整数列表同时保存在内存中，峰值占用随文件规模增长。逐行迭代只保留当前行和累计量，空间复杂度接近 O(1)。`tracemalloc` 可记录 Python 分配内存的峰值，用数据验证优化效果。

## 步骤

1. 可重复生成 200000 行整数数据，并记录行数和字节数。
2. 实现整文件读取和逐行流式处理两个版本。
3. 分别测量运行时间与峰值内存。
4. 验证两种实现的记录数和总和完全一致，计算内存降低倍数。

## 结果

两种方式均处理 200000 行且得到相同总和；流式处理的峰值内存远低于一次性读取。
