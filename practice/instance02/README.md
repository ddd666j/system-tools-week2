# 实例 2：观察并调整 CPU 任务优先级

## 原理

Linux 的 nice 值表示调度谦让程度，普通用户可以把自己的进程 nice 值调大，使其更少争用 CPU。`ps` 的 `NI`、`PRI`、`%CPU` 和 `STAT` 字段用于观察优先级、CPU 使用率与状态；调整优先级不会改变程序逻辑。

## 步骤

1. 以 nice 值 10 启动 CPU 计算任务，并通过 `$!` 自动取得 PID。
2. 使用 `ps` 查看初始 `NI`、`PRI`、状态和 CPU 使用率。
3. 使用 `renice` 将 nice 值从 10 调整到 15，再次查看进程。
4. 发送 `SIGTERM`，由 Python 信号处理函数正常结束。
5. 检查退出码、信号记录、标准错误和进程存活状态。

## 预期结果

两次 `ps` 分别显示 `NI=10` 和 `NI=15`；任务收到信号 15 后正常退出，`WAIT_EXIT=0`，最终进程不存在。
