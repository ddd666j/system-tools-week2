# 实例 7：用 PDB 定位二分查找边界缺陷

## 原理

二分查找的闭区间为 `[low, high]`，当两者相等时仍有一个候选元素需要检查。错误条件 `low < high` 会跳过最后一个候选位置。PDB 可在循环处观察 `low`、`high`、`middle` 和当前值，验证控制流为何提前退出。

## 步骤

1. 运行缺陷程序，确认查找末尾元素 10 时错误返回 -1。
2. 在循环处设置 PDB 断点，观察边界和中间元素。
3. 仅把循环条件改为 `low <= high`，保存统一 diff。
4. 使用参数化测试覆盖首项、中间项、末项、不存在项和空列表。

## 结果

调试显示边界收缩到最后一个候选位置后循环提前结束；一行修复后 5 个测试全部通过。
