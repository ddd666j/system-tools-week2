# 实例 1：带信号处理的后台监控任务

## 原理

Shell 的 `$!` 能取得最近启动的后台进程 PID，避免手工抄写。`trap` 捕获 `SIGTERM` 后先记录清理信息再正常退出；`wait` 回收子进程并取得退出状态，`kill -0` 只检查进程是否仍存在。

## 步骤

1. 为 `monitor.sh` 添加执行权限并分离标准输出、标准错误。
2. 后台启动任务，通过 `$!` 自动取得 PID。
3. 使用 `ps` 检查 PID、父 PID、状态和运行时间。
4. 发送 `SIGTERM`，使用 `wait` 等待退出。
5. 检查 `cleanup.log`、心跳日志、错误日志以及进程是否消失。

## 预期结果

清理日志包含 `CLEANUP`，`WAIT_EXIT=0`，标准错误为 0 字节，最终 `PROCESS_ALIVE=no`。
