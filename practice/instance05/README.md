# 实例 5：使用 Ruff 建立快速代码反馈循环

## 原理

静态检查器无需运行程序即可发现明确的代码问题。Ruff 的 F401 规则用于检测未使用导入，`--fix` 可执行安全的机械修复；修复后必须再次检查并运行程序，避免只根据工具提示判断成功。

## 步骤

1. 在程序中保留未使用的 `import os`，运行 Ruff 并记录非零退出码。
2. 使用 `ruff check --fix` 自动删除无效导入。
3. 用统一 diff 保存修复前后差异。
4. 再次运行 Ruff，并执行程序验证输出。

## 结果

初次检查报告 F401，修复只删除 `import os`；最终显示 `All checks passed!`，程序正常统计文本。
