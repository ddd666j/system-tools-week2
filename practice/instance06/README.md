# 实例 6：用参数化测试定位空白输入缺陷

## 原理

参数化测试用同一断言覆盖多个等价输入。原实现只拒绝空字符串，纯空格和制表符在 `strip()` 后会变成空值却未被拒绝。先保存失败测试，再做最小条件修改，能够证明修复确实由测试驱动。

## 步骤

1. 为正常姓名和三种空白输入编写 6 个参数化测试。
2. 对缺陷实现运行 Pytest，保存失败输出和退出码。
3. 将条件最小修改为 `if not value.strip()`，保存 diff。
4. 再次运行全部测试并验证 6 项通过。

## 结果

修复前 2 项空白边界测试失败；仅修改一行判断后，最终 `6 passed`。
