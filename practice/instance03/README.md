# 实例 3：使用 pipefail 发现管道中的隐藏错误

## 原理

Shell 默认以管道最后一个命令的退出码作为整个管道的状态，因此上游程序失败时，后面的 `wc` 成功可能掩盖错误。启用 `set -o pipefail` 后，只要任一环节失败，管道就返回非零状态。标准错误单独重定向可保留诊断信息。

## 步骤

1. 编写输出三行数据、向 stderr 报错并以状态 7 退出的生产者。
2. 在默认设置下连接 `wc -l`，记录管道退出码、行数和错误信息。
3. 启用 `pipefail` 后运行同一管道并再次记录。
4. 用 `test` 验证默认状态为 0、`pipefail` 状态为 7。

## 结果

两次都统计出 3 行，但默认管道返回 0，而启用 `pipefail` 后返回 7，证明上游失败被正确暴露。
