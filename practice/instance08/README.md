# 实例 8：分析并缓存递归 Fibonacci

## 原理

朴素递归会重复计算相同子问题，调用次数呈指数增长。`cProfile -s cumulative` 可显示累计耗时和函数调用次数；`lru_cache` 记忆已计算结果，把重复递归转化为查表，同时保持函数接口和结果不变。

## 步骤

1. 对 `fib(32)` 的朴素递归运行 cProfile，按累计时间排序。
2. 使用 `lru_cache(maxsize=None)` 添加缓存，保存代码差异。
3. 两个版本分别运行 3 次，使用 `perf_counter` 记录耗时并计算中位数。
4. 比较每次结果，计算加速比，不写死计时数据。

## 结果

性能报告显示热点集中在递归 `fib`；缓存版本保持结果 2178309，一般可获得数千倍以上加速。
