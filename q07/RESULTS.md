# 实验结果与反思

- 缺陷程序正常退出但输出 `[1, 5, 4, 3, 4, 5, 6, 9]`，顺序错误。
- pdb 在缺陷行停下，观察到 `i=0`、`j=0`、`left[i]=3`、`right[j]=1`，确认错误代码读取 `right[i]`。
- 最小修复仅把 `result.append(right[i])` 改为 `result.append(right[j])`，没有使用 `sorted`。
- 修复后给定输入输出 `[1, 1, 2, 3, 4, 5, 6, 9]`；给定输入和重复元素两个 pytest 测试均通过。
- 错误反思：断点必须放在可执行语句上；最初设在 `else` 行不会暂停，移到实际 append 行后才得到有效变量证据。
